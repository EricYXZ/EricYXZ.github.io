微环调制器波长调节驱动器设计

2026.5

国家级大创项目 / Digital Modulator / Analog Circuits

  • 针对温漂引起的谐振波长偏移，设计兼顾波长锁定与宽范围调谐的驱动链路。

工程项目

ART：基于 ASTF 的 RTL 生成智能体

2026.11

LLM / Verilog / Python / Vivado

  • 以抽象信号转移函数（ASTF）表达自然语言电路规格，记录时钟、复位、位宽及状态更新规则。
  • 审计并修复 ASTF，通过确定性转换或模型生成 Verilog，再用仿真和 Vivado 综合验证。
  • 在三个题集、六个模型的配对评测中，仿真及综合均通过的比例从 80.1% 提升至 89.5%。
  • 获全国大学生嵌入式芯片与系统设计竞赛国家二等奖。
  • 项目仓库：GitHub（需访问权限）
